# E-Commerce Sales & Profitability Analytics | Power BI

## Project Overview

This project uses Power BI to analyse e-commerce sales, profitability, customers, products, orders, returns, and refunds. The dashboard provides interactive business insights through KPIs and visual analysis.

## Objectives

- Analyse sales and profitability performance
- Identify customer and product trends
- Analyse orders, returns, cancellations, and refunds
- Evaluate product and category performance
- Provide actionable business insights

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modelling
- Data Visualization

## Dashboard Analysis

- Executive Overview
- Sales Analysis
- Customer Analysis
- Product Analysis
- Returns & Operations

## Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Average Order Value
- Active Customers
- New Customers
- Repeat Customers
- Return Rate
- Cancellation Rate
- Total Refunds
- Average Discount %

## Key Features

- Data cleaning and transformation using Power Query
- Relational data modelling
- DAX measures and calculated KPIs
- Interactive slicers and visualizations
- Business performance and trend analysis
